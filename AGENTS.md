# AGENTS.md – Taskwarrior-Connector

Hardened fork of shenlebantongying/Taskwarrior-Connector: a Firefox extension (`firefox/`) that
POSTs the current tab to a local Rust daemon (`connector/`, binary `taskwarrior-connector`),
which runs `task add`. `README.md` is the user-facing reference (install, configuration,
security, release process); keep it in step with any change to those, this file keeps the
contracts.

- **Version**: never bump `firefox/manifest.json` or `connector/Cargo.toml` by hand.
  `bump-version.yml` sets both (one shared version, dist refuses a tag that differs from the
  crate) and dispatches the release; `build-xpi.yml` suffixes it for manual runs (AMO signs a
  version only once) and signs those on the unlisted channel, never listed.
- **Release CI**: `.github/workflows/release.yml` is generated by dist from
  `dist-workspace.toml`; edit the config and run `dist generate` (dist 0.34.0), never the file.
  Run it without `--allow-dirty`, which silently skips writing `release.yml`. Its
  `uses: $/.github/workflows/build-xpi.yml` is GitHub's self-repository syntax (dist #2456),
  valid: do not "fix" it to `./` (a review flagged it as invalid in MARSTECH-910).
- **AMO release notes**: `build-xpi.yml` adds `version.release_notes` to
  `.github/amo-metadata.json` at sign time, from the `feat`/`fix` subjects since the previous tag
  (scope and trailing `(...)` groups such as ticket IDs and `(#N)` stripped). No CHANGELOG: the
  commit subject is the release note. web-ext sends the metadata's `version` object with every
  new version.
- **Lint**: `npx web-ext@10 lint --source-dir=firefox`, the same version as CI. Connector:
  `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`.
- **Packaging**: everything under `firefox/` ships in the `.xpi`. Design sources (SVG icon
  masters in `assets/`) stay outside it.
- **Popup contract**: `popup.js` uses the IDs `title`, `url`, `tags`, `project`, `description`,
  `submit`, `status`; a renamed ID fails silently. The project list lives in
  `browser.storage.sync` (`projects`, first entry = default), loaded by `projects.js`, edited by
  `options.html`. Status styling is keyed on `#status[data-state]`, set by
  `setStatus(text, state)`.
- **Connector**: listens on `127.0.0.1:34810`, POST only. Tags are space-separated without
  `+` (the connector adds it); POST fields `title`, `url` (required), `tag`, `project` (default `Links`,
  `[A-Za-z0-9._-]{1,64}`, mirrored by `PROJECT_RE` in `projects.js`), `description` (annotation
  via `task <uuid> annotate --`, whitespace folded to one line; a failed annotation answers
  `ok` with a `warning`). A save answers the applied `project` and `annotated`: the popup flags a
  connector too old to send them. Requests need an
  `Origin: moz-extension://` header (403 otherwise); responses are JSON with a
  `Content-Length` (tiny_http keeps the connection alive, it ignores a `Connection` header).
- Issues are tracked in YouTrack (MARSTECH project), not GitHub Issues.
